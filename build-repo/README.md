# apk-studio-builds

APK Studio üçün **şəxsi (private)** build repozitoriyası. Burada yalnız GitHub Actions workflow-ları saxlanılır:

- `.github/workflows/build-apk.yml` — APK/AAB yığır (yalnız APK Studio serveri işə salır).
- `.github/workflows/cleanup.yml` — köhnə nəticələri silir.

Bu repozitoriyanı public etməyin.
